# Dokumentasi Widget Gambar Flutter (Image Widgets)

Dokumentasi ini menyajikan referensi komprehensif implementasi **7 Komponen Gambar** dalam Flutter untuk menangani pemuatan gambar dari aset lokal, internet, penyimpanan berkas internal, memori biner, serta dekorasi visual.

---

## 1. Daftar Dokumen Image Widgets

| No | Nama Widget / Konstruktor / Kelas | Fungsi Utama | Berkas Dokumentasi |
| :-: | :--- | :--- | :--- |
| 1 | **Image** | Widget perender gambar dasar | [Image.md](Image.md) |
| 2 | **Image.asset** | Gambar dari aset lokal proyek | [Image.asset.md](Image.asset.md) |
| 3 | **Image.network** | Gambar dinamis dari internet URL | [Image.network.md](Image.network.md) |
| 4 | **Image.file** | Gambar dari berkas penyimpanan internal HP | [Image.file.md](Image.file.md) |
| 5 | **Image.memory** | Gambar dari susunan memori biner (`Uint8List`) | [Image.memory.md](Image.memory.md) |
| 6 | **FadeInImage** | Gambar dengan efek pemudaran transisi halus | [FadeInImage.md](FadeInImage.md) |
| 7 | **DecorationImage** | Pelukis gambar dekorasi latar belakang `BoxDecoration` | [DecorationImage.md](DecorationImage.md) |

## 2. Struktur Generik Dokumen Widget
Setiap berkas dokumentasi `.md` disusun menggunakan 3 bagian standar berikut:
1. **Penjelasan Singkat & Fungsi**: Penjelasan peran dan fungsi utama gambar.
2. **Tabel Atribut & Penggunaannya**: Pemetaan nama atribut, tipe data Dart, dan fungsi penggunaannya.
3. **Contoh Kode Flutter**:
   - **3.1 Contoh Kode Dasar (Basic Usage)**
   - **3.2 Contoh Kode Studi Kasus UI (Academic Mobile UI)**
